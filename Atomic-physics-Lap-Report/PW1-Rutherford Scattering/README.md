# Rutherford Scattering of Alpha Particles

Nuclear Physics practical work (PW1) – Univ. of Bordj Bou Arréridj, 2026–2027.
Simulation of α-particle scattering (E = 6 MeV) and comparison with Rutherford's theory:
`θ(b) = (180/π)·2·arctan(ke²Z / (E_c·b))`, with `ke² = 1.44 MeV·fm`.

- 📄 Report: `Rutherford_Scattering.pdf` (LaTeX source: `main.tex`)
- 📊 Data: `data.csv` (100 simulated pairs b, θ for gold, Z = 79)
- 🌐 [Interactive web simulation](https://maroua-mezhoud.github.io/physics-club/simulations/rutherford-scattering/index.html)
